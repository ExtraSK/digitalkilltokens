# Digital Kill Tokens

A kill token plugin that stores the tokens with a command. So the player doesnt have to worry about losing them.

<details>
<summary>config.yml</summary>

```yaml
prefix: "&c&lDigital Kill Tokens"

item:
  material: NETHER_STAR
  name: "&c&lᴋɪʟʟ ᴛᴏᴋᴇɴ"
  lore:
    - "&8ᴇᴀʀɴᴇᴅ ʙʏ ᴋɪʟʟɪɴɢ ᴘʟᴀʏᴇʀs"

messages:
  kill_reward: "&r | You have gotten 1 &dDigital&r Token!"
  withdraw_success: "&7 | ʏᴏᴜ ᴡɪᴛʜᴅʀᴇᴡ &d%amount% &rᴋɪʟʟ ᴛᴏᴋᴇɴѕ"
  insufficient_funds: "&7 | &fʏᴏᴜ ʜᴀᴠᴇ &cɪɴѕᴜꜰꜰɪᴄɪᴇɴᴛ ꜰᴜɴᴅѕ"
  withdraw_usage: "&7 | ᴜѕᴀɢᴇ: &c/ᴛᴏᴋᴇɴѕ ᴡɪᴛʜᴅʀᴀᴡ &r(ᴀᴍᴏᴜɴᴛ)"
  balance: "&7 | &c%balance% &rᴛᴏᴋᴇɴѕ"
  admin_added: "&c&lDIGITAL TOKENS &r&7| Gave %amount% Tokens to %arg-1%"
  admin_removed: "&c&lDIGITAL TOKENS &r&7| Removed %amount% Tokens from %arg-1%"
```
